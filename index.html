☁️ Delt lagring

Koble denne kopien til en egen JSONBin. Hver kopi på ulike SharePoint-sider har sin egen JSONBin og egne data — de er ikke synkroniserte med hverandre.

Finn denne på jsonbin.io under Bins
Finn denne på jsonbin.io under API Keys
Hent endringer hvert sekunder
Ikke konfigurert. Fyll inn Bin ID og API-nøkkel for å aktivere delt lagring.
Slik setter du opp en ny kopi:
1. Gå til jsonbin.io og opprett en gratis konto
2. Klikk Bins → Create a Bin, skriv {}, lagre
3. Kopier Bin ID og API Key hit
4. Klikk Koble til — ferdig!
